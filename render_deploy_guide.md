# 🚀 Deployment Guide: Deploying to Render (render.com)

This document provides clear, step-by-step instructions to deploy the **🌱 Smart Crop Health Early Warning & Decision Support System** to **Render** for free.

---

## 🛠️ Prerequisites

1. A **GitHub** account (or GitLab/Bitbucket).
2. A free **Render** account at [https://render.com](https://render.com).
3. **Git** installed on your local computer.

---

## 📁 Files Included for Render Deployment

The repository already contains all required configuration files:

- `server.py`: FastAPI server configured to automatically serve static files (`index.html`, `style.css`, `js/`) in production and listen on dynamic `$PORT`.
- `requirements.txt`: Python package list (`fastapi`, `uvicorn`, `pydantic`, `python-multipart`, `requests`).
- `render.yaml`: Render Blueprint configuration file.
- `Procfile`: Standard process execution file for cloud web services.
- `js/api.js`: Updated to automatically target `window.location.origin` in cloud environments.

---

## 📌 Step-by-Step Deployment Options

### Option 1: Automatic Blueprint Deployment (Fastest & Recommended)

1. **Push Code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Smart Crop Health System"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/smart-crop-health.git
   git push -u origin main
   ```

2. **Deploy on Render**:
   - Log into [https://dashboard.render.com](https://dashboard.render.com).
   - Click the **New +** button in the top-right corner.
   - Select **Blueprints**.
   - Connect your GitHub repository (`smart-crop-health`).
   - Render will automatically detect `render.yaml` and configure the Web Service (`smart-crop-health-system`).
   - Click **Apply**. Render will build and launch your application!

---

### Option 2: Manual Web Service Deployment via Render Dashboard

If you prefer configuring the Web Service manually via the UI:

1. Push your repository to GitHub.
2. Go to [Render Dashboard](https://dashboard.render.com) → Click **New +** → Select **Web Service**.
3. Connect your repository.
4. Fill in the deployment details:
   - **Name**: `smart-crop-health-system`
   - **Language / Environment**: `Python 3`
   - **Region**: Select your preferred region (e.g. *Oregon, US* or *Singapore*).
   - **Branch**: `main`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn server:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Select **Free** ($0/month).
5. Click **Create Web Service**.

---

## ✅ Verifying Deployment Success

Once the build finishes (usually 1-2 minutes):

- Your live URL will be generated by Render, e.g.:
  `https://smart-crop-health-system.onrender.com`
- Test the API Health Endpoint:
  `https://smart-crop-health-system.onrender.com/api/health`
- The entire single-page application (Scanner, GIS Hotspot Map, Weather Forecast, Pest Sensors, Role Portals, Multilingual Audio) will run unified under the HTTPS domain!

## ⚡ Troubleshooting & Performance Tips

- **Free Tier Sleep Behavior**: Render's free tier Web Services enter sleep mode after 15 minutes of inactivity. The first request after sleep may take 20-30 seconds to spin back up.
- **CORS Configuration**: `server.py` has wildcard `allow_origins=["*"]` configured so cross-origin requests work smoothly.
- **Port Binding**: Always use `$PORT` in your Start Command (`--port $PORT`) so Render can route HTTP traffic dynamically.
